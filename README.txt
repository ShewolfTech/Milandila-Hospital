WIX NOTE
This package is a normal multi-page static HTML/CSS/JS site. Wix's current Headless product supports uploading a static site folder or ZIP (HTML, CSS, JavaScript and assets; up to 20 MB), but Wix says Wix Headless is not currently available to all users. In the standard Wix Editor, visible external HTML is generally handled through embeds/iframes, while more integrated custom functionality is handled with Velo or custom elements.

For implementation, the visual design and page structure can be recreated natively in Wix Studio / Wix Editor, with each HTML page mapped to a Wix page and the placeholders replaced by the final logo and approved photography.
